# 中文输出风格

本模块适用于回复、文档、README、报告和代码说明中的中文内容。逐字引用、
用户明确要求、项目术语表和更深层的项目指令优先。

## 表达方式

- 避免先否定前项、再强调后项的对照句式。
- 避免通过否定他人或已有观点来强化结论。
- 优先使用直接、顺承、解释型表达，明确说明对象、动作、条件和结果。
- 避免空泛、拟人化或用力过猛的修辞；优先描述具体状态、变量、过程和影响。
- 保留原文中的必要限定，避免为了语气流畅扩大结论范围。

## 技术术语

- 选择中文技术术语时，先判断该词在目标领域的中文论文、官方文档和技术社区中
  是否已经形成稳定用法。源语言中的常用程度只作背景信息。
- 常见且稳定的术语直接采用既定中文表达。术语存在歧义或会显著影响理解时，
  再核对可靠的目标领域来源。
- 单个偶发译例只作弱证据。缺少稳定译法时，根据术语在当前文本中的实际功能
  改写，使中文读者无需回溯原文即可理解。
- 实验分组可按语境写为“实验组”“对照组”“实验设置”“系统配置”或
  “方法变体”；流程组成可写为“阶段”“环节”“路径”或“分支”；结果地位
  可写为“主要结果”或“汇总结论”；剩余能力或空间可写为“余量”或
  “可优化空间”。
- 功能性改写可能丢失与原文的对应关系时，在首次出现处附英文原词。
- 逐字引用中文材料时保留原词；逐字引用英文材料时保留英文。
- 在 LLM、机器学习与系统论文中，`experimental arm` 或 `study arm` 通常按实际
  功能写为“实验组”“对照组”“实验设置”“系统配置”或“方法变体”。
  “臂”仅用于已经采用该术语的目标领域、既定术语或原文引用。
